# Jarvis-Voice-Assistant
Jarvis is an AI-powered desktop voice assistant built in Python that helps you interact with your computer using natural voice commands. Designed to be simple yet powerful, Jarvis can perform a wide range of tasks—just speak, and it responds intelligently.



✨ Features
🎤 Voice Command Recognition using Google's Speech Recognition API

🗣️ Text-to-Speech Responses with pyttsx3 or gTTS

🔎 Internet Functions – Open websites, search Google/Wikipedia, tell the weather

📂 System Control – Open applications, type messages, and more

🧾 Smart Typing – Say what you want Jarvis to type into any chat or app

📊 College Attendance Fetch – Automatically logs into your college portal and reads your attendance

🔐 Secure Login Options – Option to add voice or password security

🔄 Modular Design – Easy to add new commands and extend functionality

🛠️ Tech Stack
Python 3.x

speech_recognition

pyttsx3 / gTTS

pyautogui

selenium (for web automation)

playsound, datetime, webbrowser, and more

🧪 Usage
Just run the program and start speaking commands like:

Jarvis, open YouTube

Jarvis, search Python tutorials

Jarvis, type Hello, how are you?

Jarvis, tell me my attendance

Make sure your mic is connected (e.g., Audio-Technica ATR4697-USB) and working properly.
